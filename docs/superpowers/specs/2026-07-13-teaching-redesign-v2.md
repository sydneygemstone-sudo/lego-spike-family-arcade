# 六关教学重设计 v2（Dean 打回后的重构合同）

> 2026-07-13。上一版被客户否决，三大病灶：worker 自产 SVG 太丑、参数关缺"目标值+单位计算"教学环、场景不可见/大片空白。本次美术已由 Fable 5 亲绘（assets/art.js，21 个资产），worker **只做逻辑接线，禁止改动/新画任何场景图形**。

## 铁律（六关通用）
1. **美术只用 assets/art.js**。场景元素（机器人/机械臂/桥/传送带/跑道/地块/奖品/仪表）一律 import 自 art.js；**场景里禁止使用 emoji**（按钮文字前的小 emoji 图标可保留）。art.js 的图形参数（wheelAngle/armDeg/turns…）就是动画接口——用 JS 更新参数重渲染或对 SVG 内组做 transform 补间。
2. **场景第一屏可见**：进关卡即见完整游戏场景。布局：场景区占视口高 ≥52%，控制区紧随其下，禁止下半页大片空白（768×1024 与 1024×768 都要铺满、不溢出）。
3. **参数关教学环**（claw/bridge/sort 必须走完整四步）：
   ① 目标可视化（红色标记/箭头在刻度上指出目标）
   ② 单位显性化（刻度一格 = 一个单位，格子可数）
   ③ 孩子输入的是"格数/次数"，界面实时显示**单位算式**（如 `3 格 × 30° = 90°`，大字）
   ④ 演练一次不计分（"试一试"按钮），正式执行才计星
4. 吉祥物在每关开场用一句话讲清目标（≤20字），失败安慰、通关欢呼（沿用 api.mascot / api.fail / api.complete，协议不变）。

## 各关规格
### claw 抓娃娃机（教学示范关，最高优先级）
- 主场景 `clawTopScene({unitDeg, armDeg, showTargetRay})`：unitDeg 随机 30°/45°/60°；目标物（`prize(kind)` 叠放在 `clawTargetSlot(deg)` 坐标）必落在单位整数倍角度。
- 角度输入 = **格数拨轮**（不是角度滑杆）：孩子数"目标在第几格"，拨格数 N，界面大字显示 `N 格 × 30° = N*30°`，臂随确认旋转（armDeg 补间）。
- 深度：`depthGauge({totalTurns:4, turns, targetTurns})`，目标红箭头，孩子拨圈数。
- 力度：`forceGauge({value,min,max})` + 奖品脆弱度提示（玻璃杯/蛋 3-5N 轻，积木/毛绒 6-8N 稳）；min/max 绿带只在演练时显示，正式抓取隐藏（靠记忆）。
- 流程：演练任意次（试转不下爪）→ 正式抓取（转→降→夹→升，各仪表联动动画）→ 三参数全对入篮。星级：正式第 1 次成功 3★ / 2-3 次 2★ / ≥4 次 1★。
### bridge 精准渡桥
- `bridgeScene({steps})`（steps 4-8 随机）+ `roverSide({wheelAngle})` 图层置于 `bridgeRoverX(step)`。
- 教学环：「试转 1 圈」按钮 → 机器人走 1 格并轮转 360°（单位示范，可反复）→ 大字算式 `桥长 6 步 × 1 圈/步 = 6 圈` 由孩子拨圈数触发校验 → 正式前进。过头 = 掉水（roverSide face:oops + 水花圈），不足停桥上可补拨一次。星级沿用（一次精准 3★/补拨 2★/掉水后过 1★）。
### sort 仓库分拣
- `beltScene({n})`（n 3-5）：包裹带编号可数。设定 Repeat = 包裹数（算式 `4 个包裹 = Repeat 4 次`）。
- 运行时给包裹区盖"质检暗箱"盖板（半透明深色圆角矩形，art 风格一致即可，允许 worker 用纯 CSS 做这一个遮罩），孩子看不见剩余包裹；到震动点屏幕晃动+1.5s 内点「卸货」。中途随机点暂停问「暗箱里还剩几个包裹？」四选一（保留现有中途提问逻辑，正确答案 = 剩余数）。
- roverSide 沿带体走位；卸货成功包裹飞入仓库门动画。
### race 避障接力
- 首屏即 `trackScene({tiles})`（7-9 格随机嵌 2-4 块红/绿瓷砖）+ `roverTop` 在起点；`trackCellX(i)` 定位。
- 规则设置区改为两张"if-then 积木卡"（CSS 积木造型：橙色 if 头 + 条件色块 + 动作槽），下拉/点选动作（正确项 + 干扰项保留趣味）。
- 运行：roverTop 沿格平移，到瓷砖处暂停弹规则问答（.modal-card），答对执行动作动画（红：等1s原地转圈；绿：加速冲 2 格）。星级按答对率。
### hunt 网格寻宝
- 机制不变（已验证可玩）。替换美术：网格地块用 `tiles.grass/rock/gem`，机器人用 `roverTop`（DOM/SVG 图层平移+rotate 补间，可弃用 Canvas 渲染器），宝藏 gem、起点 flag。
### macro 口诀大师
- 目标路径条：重复片段用同色底框分组高亮（如 `前进 左转 | 前进 左转 | 前进`，两组同色描边框），标题改「找一找重复的一组！」。
- 底部加执行步道：无瓷砖的 `trackScene({tiles:[null,...]})` 简化版或直接复用 hunt 网格，roverTop 按主程序走位；My Block 展开翻卡动画保留。
- 星级不变（用宏且卡数≤最优 3★）。

## 追加备注（2026-07-13 · 收尾部署时调整）
规则 2「场景区占视口高 ≥52%」在 claw/sort/macro（以及程度较轻的 race/bridge）上实测导致宽幅 SVG
场景在固定高框内被上下留白撑开（letterbox）——客户对空白零容忍，优先级高于死守 52% 这个数字。
本次收尾把场景容器改为"按内容宽高比自适应高度、上限 56vh"（claw/sort/macro）/ 53-54vh（race/bridge
维持各自原数值）：容器不再固定高度拉伸 SVG，而是让 SVG 按 viewBox 宽高比 + 容器宽度自然撑出高度，
只在极端宽高比时才顶到上限。claw 的场景+双仪表侧栏额外把左右分栏比例从 1.5:1 调整为 3:1——按
clawTopScene(410x260) 与 depthGauge(170x210)+forceGauge(236x150) 堆叠后的宽高比换算出的平衡点，
让两侧不再互相拉伸出空白。原则：场景清晰可见、无大片空白，比死守 52% 视口高更重要。
