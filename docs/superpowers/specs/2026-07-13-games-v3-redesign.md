# 游戏 v3 全面重做规格（Dean 逐关点评后）

> 2026-07-13 深夜。Dean 逐关点评结论：hunt 是黄金标准（"理想中的能进行编程实验的游戏"）；claw 视角与参数关系混乱需按新概念重做；race 维度太浅需改成全新链式谜题；sort/bridge "看到几个拨几个"无思考量需加深；每关要有 level 递进；新增"真人互动"大分类。
> **设计哲学（hunt 黄金标准的四要素，所有游戏必须对齐）**：①开放解空间（不是唯一填空）②动手前需要规划（工作记忆预演）③执行过程可视化可追踪 ④错了能看出错在哪、调整再来（debug 循环）。凡不满足的设计一律打回。

## 通用：Level 体系
- 每关 3 个 level（L1 入门 / L2 进阶 / L3 挑战），关内通关后弹"下一难度"入口，也可从关卡页直接选（已通的 level 显示星星）。
- 存档 schema v2：`stars` 变为 `{hunt: {l1:0-3, l2:0-3, l3:0-3}, ...}`（store.js 做 v1→v2 迁移，旧单值放入 l1）。徽章 = 该关 L1-L3 全部 ≥1 星后，拿满 9 星升级金徽章（badge 加 tier）。
- 首页每关卡片显示 9 星进度（3 level × 3 星）。

## 一、claw 抓娃娃机 v3（按 Dean 口述概念彻底重做）
**核心概念转变**：不再有角度/量角器。教学核心 = **motor 转 N 圈 → 水平移动 N 个单位**（move motor for rotations 的位移语义）+ 夹爪力。
- **单一视角**：侧视娃娃机机厢（新美术 `clawMachineScene`）：顶部水平导轨，爪车挂在导轨左端（0 位），机厢底部一排位置格（编号刻度 1-8），奖品停在某格。**下降深度固定**（爪缆长度刚好够到底部，不需要玩家调）。
- 玩法：数"奖品在第几格" → 拨"移动圈数"（实时预览：每 +1 爪车沿导轨滑动一格并且导轨齿轮转一圈动画+咔哒声）→ 算式 `N 圈 × 1 格/圈 = 第 N 格` → 设夹爪力（forceGauge + 奖品脆弱度）→ 「出发抓取」：爪车横移（轮齿转动）→ 自动下降 → 夹（力度判定）→ 提起 → 滑回 0 位放入出奖口。
- 失败反馈可视化（debug 要素）：圈数不对→爪子下降抓空，落点与奖品的偏差直接可见（"差 1 格！"）；力太大→捏碎；力太小→滑落。每次失败后参数保留，孩子微调重试。
- Level：L1 每圈=1格（数格即圈数）；L2 **每圈=2格**（奖品在第 6 格 → 3 圈，乘法/除法换算，若奖品在奇数格则该 level 生成时保证偶数格）；L3 每圈=2格 + 起点不在 0（爪车起始停在第 2 格，要算相对位移 = (目标-起点)÷2，允许负方向=反转圈数往回移）。
- 星级（每 level）：正式 1 次成功 3★ / 2-3 次 2★ / 完成 1★；演练不限次不计分。

## 二、race → 重命名「机关轨道」(id 不变 race) v3（Dean 口述的链式指令谜题，彻底重做）
**核心概念**：机器人自己不会走！轨道每格可以放一块指令块，机器人被指令"接力"传递——落在格 i 就执行格 i 的块，被送到格 j，再执行格 j 的块……直到落在目标格（宝石）胜利。**块与块的耦合链就是程序**。
- 轨道横向 7-10 格（复用 trackScene 改造：格子空/目标宝石格/起点旗）。目标格可在中途（Dean 点名）。
- 指令块托盘（数量有限=资源约束，用 blocks-ui 风格拖到轨道格上）：`➡️ 前进2格` `➡️ 前进3格` `⬅️ 后退1格` `🦘 跳过下一格（跳到+2）` 等，每关给定几种、每种限量。
- 执行规则（清晰可教）：机器人从起点格开始执行该格的块 → 按块位移 → 落格执行新格的块 → 落在**空格 = 程序停机失败**（除非那格就是目标）→ 落在目标格 = 胜利 ✦ 执行超过 15 步仍未到 = "程序转圈圈啦！"（**死循环概念**，用后退+前进块可能造出循环，失败动画幽默）。
- 执行可视化（黄金标准四要素）：roverTop 逐格跳动，当前执行块高亮发光，走过的轨迹画弧线；失败时停在出错格，出错原因一句话（"落在了空格上，程序停机了！"）——孩子看着轨迹调块。
- Level：L1 4-5 格 2 种块（前进2/前进3），目标在尾部，1-2 解；L2 6-8 格加跳过块+干扰空格；L3 8-10 格加后退块（可造循环），目标在中途，必须"冲过头再退回来"。
- 关卡生成：随机布局后 BFS 验证必有解且最优解块数 ≥2 才采用。星级：最优块数 3★ / 多 1 块 2★ / 完成 1★。

## 三、sort → 重命名「流水线密码」(id 不变 sort) v3（重新设计，循环结构的真思考版）
**核心概念**：传送带送来一串**有周期规律的彩色包裹序列**（如 红蓝蓝·红蓝蓝·红蓝蓝），机器人的分拣程序 = `Repeat [n] × { 动作槽1, 动作槽2, ... }`。孩子要**发现序列的循环规律**，把"一个周期"填进循环体、算出循环次数——循环体 × 次数必须精确覆盖整个序列。
- 界面：上方 beltScene 改造版（包裹变彩色可配置，编号保留）；下方"循环程序机"：`Repeat [拨轮 n] 次 {` + 2-4 个可拖动作槽（拖入 装红箱🔴/装蓝箱🔵/装黄箱🟡 块）+ `}`。
- 执行：机器人站在带旁，逐包裹执行程序展开序列，配对正确→包裹飞入对应颜色箱；错→包裹弹地上（滑稽）+ 停机显示"第 k 个包裹出错了"，孩子看出错位置改程序（debug 循环）。
- 算式呈现：`循环体 3 个动作 × Repeat 3 次 = 处理 9 个包裹`（覆盖检查也是教学：序列 9 个，程序只盖 6 个→提示"还剩 3 个没处理哦"）。
- Level：L1 纯周期序列（周期 2，共 6 个）；L2 周期 3 共 9-12 个；L3 序列 = 前缀 + 循环段（如 黄·红蓝红蓝红蓝：先单独处理黄=循环外的前置动作槽，再 Repeat），教"不是所有东西都在循环里"。
- 星级：一次跑通 3★ / 一次 debug 后 2★ / 完成 1★。

## 四、bridge 精准渡桥 v3（保留框架，深度升级）
**核心升级**：从"数几步拨几圈"升级为**轮子组合的线性方程**。
- L1（保留现状机制做入门）：小轮 1圈=1步，桥长 N 步 → N 圈（试转一圈演示保留）。
- L2 **双轮换装**：出发前选装 大轮（1圈=2步）或 小轮（1圈=1步），桥长 7 步 → 大轮拨 3 圈 + 换小轮 1 圈（两段行程 UI：第一段轮型+圈数、第二段轮型+圈数），多解（也可 小轮×7）！算式 `3圈×2步 + 1圈×1步 = 7 步`。星级奖励总圈数最少的解（3+1=4 圈拿 3★，纯小轮 7 圈拿 2★）——**教优化思想**。
- L3 **往返任务**：过桥到对岸拿旗（N 步）再回到起点（N 步），一次性预设两段程序（去程圈数+回程圈数），中途不能改；桥长随机且去程用大轮回程用小轮（或反之，装轮顺序随机指定），考两段换算+工作记忆。
- 美术沿用 bridgeScene + roverSide，大轮/小轮 = roverSide 的 wheel 半径参数化（art.js 我会加 `wheelScale` 参数，worker 不许自己画）。

## 七、真人互动分类「一起玩」（全新，6 个游戏，iPad = 主持人/裁判/节拍器，孩子+家长真人执行）
首页改造：两个分区标签「屏幕编程」（现有 6 关）/「一起玩」（新 6 个，家庭真人游戏，数字辅助）。真人游戏不计星（或简单完成打卡），重在工具性。共享一个"主持人框架"（大字卡显示+计时器+节拍音效+翻牌对答案交互）。
1. **人体机器人（你说我做）**：iPad 出动作组合卡（图标+文字，如"左手摸右耳 + 单脚站 + 数 3 秒"）只给描述者看；描述者用语言指挥（禁止比划），执行者做完 → iPad 翻面亮出原卡对照 → 两人自评 对/错。教：精确指令传达（编程语言本质）。角色互换按钮。
2. **客厅寻宝（真人版 hunt）**：iPad 生成指令序列卡（前进 3 步→左转→蹲下捡起…），孩子当机器人在客厅执行，家长当"编译器"核对每步；进阶模式：孩子先看完整序列、口头预言终点位置再执行验证（脑内预演=工作记忆）。
3. **节奏程序（节奏天国概念）**：iPad 显示动作循环序列（👏拍手 🦵拍腿 👏拍手 🦶跺脚 = 一个循环）+ 节拍音效，跟拍执行，每轮循环速度 +10%，坚持 4 轮过关；教 loop + 节奏工作记忆。动作图标大字轮播 + 节拍声（sfx 扩展一个 tick 音）。
4. **口令宏（真人 My Block）**：第一步全家共同定义宏（"忍者闪避"=蹲+跳+转圈，iPad 记录动作序列）；第二步 iPad 随机播报指令流（单动作与宏名混合），听到宏名要完整展开做出整套；教抽象与组块。
5. **如果就（条件反射）**：先约定规则卡（🔴红屏→立刻定住 / 🟢绿屏→原地跳 / 🔊听到"哞"→蹲下），iPad 随机亮色/播声（间隔渐短），做错自罚重来；教 if-then + 抑制控制（ADHD 核心训练点）。
6. **人体传送带（真人 sort）**：孩子背小包装 N 块积木沿地垫走，iPad 每隔随机节拍"叮"一声=取出一块放地上，全程心里倒数，结束 iPad 问"包里还剩几块？"输入答案对照；教循环计数 + 工作记忆刷新。
- 美术：动作图标集（简笔小人：蹲/跳/转圈/拍手/单脚站/摸耳/跺脚/定住/拍腿/举手，10 个）由 Fable 5 画进 art.js（`actionIcons`），worker 禁止自画。
